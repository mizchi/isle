setup module と CSS を読み込み、setup から見える適用済み style を調べる。 card.css と setup.mjs を読む。活性化後の data-style-at-setup が ready になり、setup 前に CSS が適用されたことを示す。CSS 分割は Vite が扱い、class 単位の CSS DCE は未実装。

リポジトリ内の例は、ルートで上記コマンドを実行する。検査は just examples-check。利用者のアプリへ組み込む場合は npm パッケージの導入手順を使い、このディレクトリのソースと設定を参照する。

実装を読む

app.isle
client component Card() {
  state count = 0;
  <section class="lazy-card">
    <h2>Component CSS</h2>
    <button type="button">on click activate { count += 1; }Activate style</button>
    <output aria-live="polite">{count}</output>
  </section>
}
card.css
.lazy-card { --card-ready: ready; border-top: 6px solid #08665c; background: #eaf3f1; }
.lazy-card h2 { color: #064c45; }
setup.mjs
import './card.css';
export function setup({ root }) {
  // The loader waits for this CodeRef's stylesheet before calling setup.
  root.dataset.styleAtSetup = getComputedStyle(root).getPropertyValue('--card-ready').trim();
}
vite.config.mjs
import { exampleConfig } from '../_shared/vite.mjs';
export default exampleConfig(import.meta.url, {
  resources: { Card: './setup.mjs' },
  mounts: [{ component: 'Card', props: {}, label: 'CSS readiness' }],
});
