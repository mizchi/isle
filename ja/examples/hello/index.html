最小の Counter

SSR した値を増やし、初期値へ戻す。

ライブデモを開く ↗GitHub source ↗

SSR した値を増やし、初期値へ戻す。 app.isle と vite.config.mjs を一緒に読む。状態・表示の宣言はコンパイルされ、名前付き handler が追跡できるコード境界になる。

リポジトリ内の例は、ルートで上記コマンドを実行する。検査は just examples-check。利用者のアプリへ組み込む場合は npm パッケージの導入手順を使い、このディレクトリのソースと設定を参照する。

実装を読む

app.isle
client component Counter(initial: number) {
  state count = initial;
  derive doubled = count * 2;
  <section>
    <h2>Counter</h2>
    <output aria-live="polite">{count} / {doubled}</output>
    <button type="button">on click increment { count += 1; }Increment</button>
    <button type="button">on click reset { count = initial; }Reset</button>
  </section>
}
vite.config.mjs
import { exampleConfig } from '../_shared/vite.mjs';
export default exampleConfig(import.meta.url, {
  mounts: [{ component: 'Counter', props: { initial: 5 }, scopeId: 'counter', label: 'Counter' }],
});
