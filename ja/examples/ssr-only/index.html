ブラウザー JS のない SSR

ビルドに Isle runtime・snapshot・handler chunk が含まれないことを確認する。

ライブデモを開く ↗GitHub source ↗

ビルドに Isle runtime・snapshot・handler chunk が含まれないことを確認する。 SSR 専用の指定はページ全体に適用する。無指定の純粋 component は server/client 共通で使える。アプリが別途追加する外部 script は対象外。

リポジトリ内の例は、ルートで上記コマンドを実行する。検査は just examples-check。利用者のアプリへ組み込む場合は npm パッケージの導入手順を使い、このディレクトリのソースと設定を参照する。

実装を読む

app.isle
component Notice(title: string, message: string) {
  <article><h2>{title}</h2><p>{message}</p></article>
}

server component Page() {
  <section><Notice title="HTML is enough" message="No browser initialization or handler chunks are needed." /></section>
}
vite.config.mjs
import { exampleConfig } from '../_shared/vite.mjs';
export default exampleConfig(import.meta.url, {
  mode: 'ssr', mounts: [{ component: 'Page', props: {}, label: 'Static page' }],
});
