静的な検査結果

CSS 契約の3つの結果

reset を考慮した Grid 契約で verified・overflow の violated・未対応の unknown を試す。

CSS 契約はビルド時に検査します。verified / violated / unknown の実際の結果を確認できます。

検査結果を読む →

reset を考慮した Grid 契約で verified・overflow の violated・未対応の unknown を試す。 下の3設定を実行する。verified のみ終了コード0、violated と unknown は1。宣言したサイズ・テキスト契約の範囲の検査であり、unknown は検証成功ではない。

リポジトリ内の例は、ルートで上記コマンドを実行する。検査は just examples-check。利用者のアプリへ組み込む場合は npm パッケージの導入手順を使い、このディレクトリのソースと設定を参照する。

sh
node tools/isle.mjs layout examples/layout-contracts/app.isle examples/layout-contracts/layout.json
node tools/isle.mjs layout examples/layout-contracts/app.isle examples/layout-contracts/overflow.json
node tools/isle.mjs layout examples/layout-contracts/app.isle examples/layout-contracts/unknown.json

実装を読む

app.css
@layer app {
  .panel {
    display: grid;
    grid-template-columns: minmax(0, 1fr);
    grid-template-rows: minmax(0, 1fr);
    padding: 16px;
    block-size: 100%;
    font-family: system-ui;
    line-height: 24px;
  }
  .copy { inline-size: 100%; block-size: 100%; padding: 16px; overflow-wrap: anywhere; }
}
app.isle
component ResetPanel() {
  <main class="panel"><p class="copy">Reset-aware box model</p></main>
}
