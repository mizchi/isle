Speculation Rules の data block と通常リンクを確認する。Isle の browser JS は出力しない。 Speculation Rules は browser のヒントであり、取得の実行を保証しない。未対応環境でも通常リンクで遷移できる。この例は prefetch のみ。prerender は遷移先の script を実行し得る。handler chunk の先読みとは別機能。

リポジトリ内の例は、ルートで上記コマンドを実行する。検査は just examples-check。利用者のアプリへ組み込む場合は npm パッケージの導入手順を使い、このディレクトリのソースと設定を参照する。

実装を読む

app.isle
component Notice() { <p>This page needs no Isle browser JavaScript.</p> }
vite.config.mjs
import { fileURLToPath } from 'node:url';
import { exampleConfig } from '../_shared/vite.mjs';
const config = exampleConfig(import.meta.url, {
  mode: 'ssr', mounts: [{ component: 'Notice', props: {}, label: 'Native navigation' }],
  speculation: {
    tag: 'isle-example',
    prefetch: [{ where: { selector_matches: 'a[data-prefetch]' }, eagerness: 'moderate' }],
  },
});
config.build.rolldownOptions = {
  input: { index: fileURLToPath(new URL('index.html', import.meta.url)), next: fileURLToPath(new URL('next.html', import.meta.url)) },
};
export default config;
