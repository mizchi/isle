サーバーが必要

共通 schema とサーバー検証

taken@example.com の重複エラーを確認し、修正・送信・reset を試す。

この例にはサーバーが必要です。GitHub Pages には RPC endpoint を置かず、下の host と実行手順を使います。

taken@example.com の重複エラーを確認し、修正・送信・reset を試す。 taken@example.com はメモリー内で使用済み。非同期検証と submit が公開可能な field issue を返す。host の principal はデモ固定値で実認証ではない。

リポジトリ内の例は、ルートで上記コマンドを実行する。検査は just a11y-schema-form。利用者のアプリへ組み込む場合は npm パッケージの導入手順を使い、このディレクトリのソースと設定を参照する。

実装を読む

app.isle
schema Registration {
  email: string minLength(3) maxLength(80) format("email");
  confirmation: string minLength(3) sameAs(email);
  age: number min(18) max(120) integer();
  accepted: boolean equals(true);
}

view Registered { email: string; }
export server action register(input: Registration): Registered
  using request: RequestContext
  authorize grant = policy.signup(request, input.email)
  validate accounts.available effects { db.read }
  effects { db.write }
{ return await accounts.register(grant, input.email); }

export client component SchemaSignup() {
  <form schema="Registration" submit="register" aria-label="Create account">
    <label>Email (required)<input name="email" autocomplete="email" /></label>
    <label>Confirm email (required)<input name="confirmation" /></label>
    <label>Age (required)<input name="age" value="21" /></label>
    <label><input name="accepted" />I agree (required)</label>
    <button type="submit">Create account</button>
    <button type="reset">Reset</button>
  </form>
}
host.mjs
// Local demo only: the request principal is fixed. Registration is an in-memory write.
const accounts = new Set(['taken@example.com']);
export const host = {
  context: () => ({ subject: 'demo', tenant: 'local' }),
  policies: { 'policy.signup': context => context.tenant === 'local' },
  validators: { 'accounts.available': { effects: ['db.read'],
    validate: async ({ input }) => accounts.has(input.email) ? [{ field: 'email', code: 'taken' }] : [] } },
  operations: { 'accounts.register': { policy: 'policy.signup', effects: ['db.write'],
    commit: ({ args }) => { accounts.add(args[1]); return { email: args[1] }; } } },
};

  build: { outDir: '../../dist-schema-form', emptyOutDir: true, manifest: true },
});
