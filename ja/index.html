THE IDEA

境界を明示し、仕事を減らす。

何を先に決め、何を操作まで待つか。専用の宣言で、その判断をコンパイラに伝えます。

01

初期化を繰り返さない

サーバーで作った HTML と保存した状態を使います。コンポーネント全体の初期化をブラウザーでやり直しません。

02

更新する場所を先に知る

状態と表示の依存をビルド時に解析。変化に関係する DOM を更新するコードを生成します。

03

Web のまま配る

ES2023、DOM、ES modules。通常ページにも、独立した Web Components widget にも。MoonBit / Wasm runtime の配布は不要です。

HOW IT WORKS

宣言から、再開まで。

  1. 01

    UI を宣言する

    状態、表示、イベントと server action の境界を .isle に書きます。

  2. 02

    ビルドで分ける

    SSR の HTML、snapshot、分割された JS / CSS と manifest を生成します。

  3. 03

    操作された UI を再開する

    コードの取得と実行を分け、必要な状態を復元して動的な表示だけを更新します。
