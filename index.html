THE IDEA

Clear boundaries. Less work.

Decide what belongs in the page and what can wait. Give the compiler enough structure to make that separation.

01

Resume, without replay

Use the HTML and saved state from the server. Component initialization does not run all over again in the browser.

02

Know what can change

Analyze state-to-view dependencies at build time. Generate update code for the DOM affected by each change.

03

Ship the web platform

ES2023, DOM and ES modules. Build regular pages or independent Web Components widgets, without a MoonBit / Wasm runtime.

HOW IT WORKS

From declaration to interaction.

  1. 01

    Declare the UI

    Write state, views, events and explicit server action boundaries in .isle.

  2. 02

    Split at build time

    Generate SSR HTML, snapshots, split JS / CSS and a dependency manifest.

  3. 03

    Resume on interaction

    Separate fetching from execution. Restore needed state and update dynamic output.
