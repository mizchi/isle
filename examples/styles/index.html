Lazy CSS readiness

Load component CSS with its setup module and inspect the style seen by setup.

Open live demo ↗GitHub source ↗

Source / ソース: app.isle · card.css · setup.mjs · vite.config.mjs

Load component CSS with its setup module and inspect the style seen by setup. Inspect card.css and setup.mjs. data-style-at-setup becomes ready on activation, showing that CSS was applied before setup. Vite handles CSS splitting; class-level CSS dead-code elimination is not implemented.

From a repository checkout, run at the repository root:

sh
just example styles

Check: just examples-check. For a consumer app, install the package and use the npm setup; the source files here show the feature and its configuration.

app.isle
client component Card() {
  state count = 0;
  <section class="lazy-card">
    <h2>Component CSS</h2>
    <button type="button">on click activate { count += 1; }Activate style</button>
    <output aria-live="polite">{count}</output>
  </section>
}
card.css
.lazy-card { --card-ready: ready; border-top: 6px solid #08665c; background: #eaf3f1; }
.lazy-card h2 { color: #064c45; }
setup.mjs
import './card.css';
export function setup({ root }) {
  // The loader waits for this CodeRef's stylesheet before calling setup.
  root.dataset.styleAtSetup = getComputedStyle(root).getPropertyValue('--card-ready').trim();
}
vite.config.mjs
import { exampleConfig } from '../_shared/vite.mjs';
export default exampleConfig(import.meta.url, {
  resources: { Card: './setup.mjs' },
  mounts: [{ component: 'Card', props: {}, label: 'CSS readiness' }],
});
