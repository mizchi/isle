Inspect the build: HTML and CSS, with no Isle runtime, snapshots or handler chunks. The mode applies to the whole page. A pure component also works on both server and client without a side annotation. External scripts added by your app are outside this guarantee.

From a repository checkout, run at the repository root:

sh
just example ssr-only

Open http://127.0.0.1:4321/.

Check: just examples-check. For a consumer app, install the package and use the npm setup; the source files here show the feature and its configuration.

Read the implementation

app.isle
component Notice(title: string, message: string) {
  <article><h2>{title}</h2><p>{message}</p></article>
}

server component Page() {
  <section><Notice title="HTML is enough" message="No browser initialization or handler chunks are needed." /></section>
}
vite.config.mjs
import { exampleConfig } from '../_shared/vite.mjs';
export default exampleConfig(import.meta.url, {
  mode: 'ssr', mounts: [{ component: 'Page', props: {}, label: 'Static page' }],
});
