Selective DOM updates

Change one value while the static heading and unrelated output keep their DOM identity.

Open live demo ↗GitHub source ↗

Source / ソース: app.isle · vite.config.mjs

Change one value while the static heading and unrelated output keep their DOM identity. Inspect generated handler chunks: increment writes count and its derived text; editing the note does not touch count. Browser tests observe actual DOM mutations.

From a repository checkout, run at the repository root:

sh
just example partial-updates

Open http://127.0.0.1:4322/.

Check: just examples-check. For a consumer app, install the package and use the npm setup; the source files here show the feature and its configuration.

app.isle
client component Dashboard() {
  state count = 0;
  state note = "Unchanged";
  derive doubled = count * 2;
  <section>
    <h2 data-static="">This heading is static</h2>
    <p>Count <output data-count="">{count}</output></p>
    <p>Doubled <output data-doubled="">{doubled}</output></p>
    <p>Independent note <output data-note="">{note}</output></p>
    <button type="button">on click increment { count += 1; }Increment</button>
    <button type="button">on click edit { note = "Edited"; }Edit note</button>
  </section>
}
vite.config.mjs
import { exampleConfig } from '../_shared/vite.mjs';
export default exampleConfig(import.meta.url, {
  mounts: [{ component: 'Dashboard', props: {}, label: 'Selective updates' }],
});
