Resource lifetime and cleanup

Activate an owned timer and listener, remove the component, and observe one cleanup.

Activate an owned timer and listener, remove the component, and observe one cleanup. First activate the session, then use Remove component. The resource owner clears the timer and removes the listener when the root disconnects; the outside status reports one disposal. Setup lives in an ordinary JavaScript module.

From a repository checkout, run at the repository root:

setup.mjs
export function setup({ root, owner }) {
  const status = document.querySelector('#lifecycle');
  let ticks = 0;
  status.textContent = 'Active';
  status.dataset.state = 'active';
  const timer = setInterval(() => { status.textContent = `Active: ${++ticks} ticks`; }, 1000);
  owner.own(timer, clearInterval);
  const entered = () => { root.dataset.entered = 'true'; };
  root.addEventListener('pointerenter', entered);
  owner.own(root, element => {
    element.removeEventListener('pointerenter', entered);
    status.textContent = 'Disposed: timer and listener released';
    status.dataset.state = 'disposed';
    status.dataset.cleanups = String(Number(status.dataset.cleanups ?? 0) + 1);
  });
}

export default exampleConfig(import.meta.url, {

  mounts: [{ component: 'Session', props: {}, label: 'Owned resources' }],
});
