Native navigation hints

Inspect a native Speculation Rules data block and follow an ordinary link; no Isle browser JS is emitted.

Inspect a native Speculation Rules data block and follow an ordinary link; no Isle browser JS is emitted. Speculation Rules are browser hints, not a promise of prefetch. Unsupported browsers still follow the link normally. This example uses prefetch only; prerender may evaluate scripts on the destination. It does not preload handler chunks.

From a repository checkout, run at the repository root:

sh
just example navigation

Open http://127.0.0.1:4327/.

Check: just examples-check. For a consumer app, install the package and use the npm setup; the source files here show the feature and its configuration.

Read the implementation

app.isle
component Notice() { <p>This page needs no Isle browser JavaScript.</p> }
vite.config.mjs
import { fileURLToPath } from 'node:url';
import { exampleConfig } from '../_shared/vite.mjs';
const config = exampleConfig(import.meta.url, {
  mode: 'ssr', mounts: [{ component: 'Notice', props: {}, label: 'Native navigation' }],
  speculation: {
    tag: 'isle-example',
    prefetch: [{ where: { selector_matches: 'a[data-prefetch]' }, eagerness: 'moderate' }],
  },
});
config.build.rolldownOptions = {
  input: { index: fileURLToPath(new URL('index.html', import.meta.url)), next: fileURLToPath(new URL('next.html', import.meta.url)) },
};
export default config;
